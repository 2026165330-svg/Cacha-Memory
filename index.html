CACHE MEMORY

What is Cache Memory?

Cache memory is a small and very fast type of memory located close to the CPU. It stores frequently used data so the CPU can access it faster.

How Does Cache Memory Work?

When the CPU needs information, it first checks the cache. If the information is found, this is called a Cache Hit. If it is not found, this is called a Cache Miss, and the computer must get the information from RAM.
